# `data/` — Organização dos Dados do Projeto GlaucPIO

Esta pasta contém os dados do projeto, organizados em **3 níveis**:

- **`raw/`** — dados brutos, intocados
- **`processed/`** — dados transformados (limpeza, features, splits)
- **`../outputs/`** — resultados finais (avaliações, figuras, logs)
